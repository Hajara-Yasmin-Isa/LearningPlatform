# Co-scoring: 10 replies (about 15 minutes)

Thanks for helping! These are 10 replies from AI tutor models. We want a second opinion so the bake-off scores aren't one person's judgement.

1. Read the rubric: `docs/ai/bakeoff/rubric.md` (one page). Note the strictness rules at the bottom.
2. Open `sheet.csv`. Each row has the question, what the student answered, the correct answer, and the tutor's reply.
3. Score each reply 0, 1 or 2 in `no_reveal`, `correct`, `helpful`, `length_tone`. Leave `no_reveal` as N/A where it's already filled in. Add a short note if a call was hard.
4. **Don't open `key.csv`.** It says which model wrote each reply and the first scorer's scores.
5. Send the sheet back to Bijou. We'll compare, talk through every difference of 1 point or more, and record the outcome in proposal 002.
